One master, everyone else listens for their turn. The master transmits a header (break + sync + PID) naming which message comes next. Whichever node owns that ID responds — usually a slave, sometimes the master itself. There's no contention to resolve, because only one node is ever invited to talk. Every byte on LIN — sync, PID, data, checksum — is framed like a UART byte: start bit, 8 data bits LSB-first, stop bit. CAN has no such thing; this is a LIN-specific detail.

Not a shared bus at all. Every ECU has its own private, full-duplex link to a switch — nobody's signal is ever on the same wire as anybody else's. There's nothing to arbitrate: two nodes can transmit at the exact same instant with zero conflict. The switch reads the destination address and forwards the frame down one port only; other nodes never even see it electrically. Try sending both slots below at once.
